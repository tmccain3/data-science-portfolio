FEATURED PROJECT

Predicting Business AI Use

A machine-learning project using business survey data to predict reported AI-use outcomes. The analysis moves from data preparation and exploratory analysis through baseline modeling, model comparison, cross-validation, error analysis, and model interpretation.

PREDICTION PROBLEM Can machine-learning models predict the percentage of businesses within a sector and employee-size group that report using AI, not using AI, or not knowing whether they use AI?
Python Pandas Scikit-learn Multi-Output Regression Cross-Validation Model Evaluation
View Full Project
01

Prediction

Predict three continuous AI-use percentages across 89 sector and employee-size groups using business characteristics and survey measures.

02

Model Comparison

Compare a mean baseline, Decision Tree, Random Forest, and Gradient Boosting using the same five-fold cross-validation strategy.

03

Model Selection

Select the preferred trained model using the lowest cross-validated Mean Absolute Error rather than relying only on training performance.
